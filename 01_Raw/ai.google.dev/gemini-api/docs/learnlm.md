# LearnLM

LearnLM এখন আর AI Studio-তে আলাদা তালিকা হিসেবে নেই। পরিবর্তে, LearnLM-এর
ক্ষমতা Gemini-তে ইন্টিগ্রেট করা হয়েছে, যা শুরু হয়েছে
[2.5 মডেল সিরিজ](https://ai.google.dev/gemini-api/docs/models?hl=bn) থেকে।

LearnLM-এর বর্তমান স্ট্যাটাস সম্পর্কে আরও জানতে,
[LearnLM](https://cloud.google.com/solutions/learnlm?hl=bn) ডকুমেন্টেশন দেখুন।
