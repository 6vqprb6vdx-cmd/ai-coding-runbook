# رصد إساءة الاستخدام

تلتزم Google بتطوير الذكاء الاصطناعي واستخدامه بشكل مسؤول. لضمان سلامة واجهة Gemini API وسلامة البيانات فيها، وضعنا إرشادات السياسة هذه.
باستخدام Gemini API، أنت توافق على الإرشادات التالية و[بنود الخدمة الإضافية الخاصة بـ Gemini API](https://ai.google.dev/gemini-api/terms?hl=ar) و[سياسة الاستخدام المحظور](https://policies.google.com/terms/generative-ai/use-policy?hl=ar) الخاصة بالذكاء الاصطناعي التوليدي.

## كيفية رصد إساءة الاستخدام

يستخدم فريق &quot;الثقة والأمان&quot; في Google مزيجًا من العمليات المبرمَجة واليدوية لرصد أي إساءة محتملة لاستخدام Gemini API وGoogle AI Studio من أجل فرض سياساتنا.

- **الرصد الآلي:** تفحص الأنظمة الآلية استخدام واجهة برمجة التطبيقات بحثًا عن أي انتهاكات لسياسة الاستخدام المحظور، مثل كلام يحض على الكراهية والتحرش والمحتوى الجنسي الصريح والمحتوى الخطير.
- **الرصد اليدوي:** إذا كان أحد المشاريع يعرض بشكل متكرر نشاطًا مريبًا، قد يتم وضع علامة عليه لمراجعته يدويًا من قِبل موظفين معتمدين من Google.

## طريقة معالجة البيانات

تحتفظ Google بالبيانات التالية لمدة خمسة وخمسين (55) يومًا لأغراض رصد انتهاكات "سياسة الاستخدام المحظور" ومنعها للحفاظ على سلامة الخدمات وأمانها، ولأي إفصاحات قانونية أو تنظيمية مطلوبة:

- **الطلبات:** هي الطلبات النصية التي ترسلها إلى واجهة برمجة التطبيقات.
- **المعلومات السياقية:** أي سياق إضافي تقدّمه مع طلباتك
- **الناتج:** الردود التي تم إنشاؤها باستخدام Gemini API

## طريقة التحقيق في المشاكل المحتملة

عندما ترصد فلاتر الأمان وأنظمة رصد إساءة الاستخدام الموضّحة أعلاه أي محتوى في الطلبات أو نواتج النماذج، يمكن لموظفي Google المفوّضين تقييم المحتوى الذي تم رصده، وتأكيد التصنيف أو التحديد أو تصحيحهما استنادًا إلى الإرشادات والسياسات المحدّدة مسبقًا. يمكن للموظفين المعتمدين في Google الوصول إلى البيانات لمراجعتها فقط من خلال تقييم داخلي للحوكمة ومنصة لإدارة المراجعات. عند تسجيل البيانات لأغراض رصد إساءة الاستخدام، يتم استخدامها فقط لفرض السياسات ومنع انتهاكها.
ولا تُستخدَم لتدريب أو تحسين أي نماذج ذكاء اصطناعي أو تعلُّم آلة باستثناء تلك المستخدَمة خصيصًا لفرض السياسات.

## العمل معك على الالتزام بالسياسات

إذا كان استخدامك لـ Gemini لا يتوافق مع سياساتنا، قد نتّخذ الخطوات التالية:

- **التواصل معك:** قد نتواصل معك عبر البريد الإلكتروني لفهم حالة استخدامك واستكشاف طرق لضمان التزامك بالسياسة.
- **حدود الاستخدام المؤقتة:** قد نحدّ من إمكانية وصولك إلى Gemini API من خلال تعديل حدود المعدّل أو تغيير النموذج الذي يجيب عن طلب معيّن، على سبيل المثال.
- **التعليق المؤقت:** قد نوقف مؤقتًا إمكانية وصولك إلى Gemini API.
- **إغلاق الحساب:** كحلّ أخير، وفي حال حدوث مخالفات جسيمة، يجوز لنا إغلاق إمكانية وصولك إلى Gemini API وخدمات Google الأخرى بشكل دائم.

إذا تواصلنا معك بشأن تعليق حسابك أو إغلاقه، سنقدّم لك أيضًا رابطًا يمكنك من خلاله تقديم طلب إعادة نظر.
