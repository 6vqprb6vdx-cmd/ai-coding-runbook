# সমস্যার সমাধান করার নির্দেশিকা

Gemini API কল করার সময় যেসব সাধারণ সমস্যা দেখা দেয় সেগুলি ডায়াগনসিস ও সমাধান করার জন্য
এই গাইড ব্যবহার করুন। আপনি Gemini API ব্যাকএন্ড পরিষেবা বা ক্লায়েন্ট SDK-এর
কোনও একটি থেকে সমস্যার সম্মুখীন হতে পারেন। আমাদের ক্লায়েন্ট SDK নিম্নলিখিত রিপোজিটরিতে
ওপেন সোর্স করা হয়েছে:

- [python-genai](https://github.com/googleapis/python-genai)
- [js-genai](https://github.com/googleapis/js-genai)
- [go-genai](https://github.com/googleapis/go-genai)

API কী সংক্রান্ত কোনও সমস্যা হলে, [API কী সেট-আপ করার নির্দেশিকা](https://ai.google.dev/gemini-api/docs/api-key?hl=bn) অনুযায়ী
আপনার API কী সঠিকভাবে সেট-আপ করেছেন কিনা তা যাচাই করুন।

## ত্রুটি কোড

HTTP স্ট্যাটাস কোড, জেনারেশন ব্লক করা কোড এবং কন্টেন্ট সংক্রান্ত সমস্যার কোড সহ সব সমস্যার কোডের সম্পূর্ণ রেফারেন্সের জন্য,
[API সংক্রান্ত সমস্যা](https://ai.google.dev/gemini-api/docs/api-errors?hl=bn) পৃষ্ঠা দেখুন।

## আবার চেষ্টা করার স্ট্র্যাটেজি

আপনি যদি এমন কোনও সমস্যার মেসেজ পান যা থেকে বোঝা যায় যে আপনাকে অনুরোধটি আবার করতে হবে (যেমন `429 RESOURCE_EXHAUSTED` বা `503 UNAVAILABLE`), তাহলে আমরা এক্সপোনেনশিয়াল ব্যাকঅফ স্ট্র্যাটেজি প্রয়োগ করার সাজেশন দিই। এর অর্থ হল, প্রথমবার আবার চেষ্টা করার আগে আপনি অল্প সময় অপেক্ষা করেন এবং তারপরে পরবর্তী প্রচেষ্টার মধ্যে অপেক্ষার সময় ধীরে ধীরে বাড়ান।

Gemini API-এর জন্য অফিসিয়াল ক্লায়েন্ট SDK, যেমন [Python SDK](https://github.com/googleapis/python-genai)-তে টাইমআউট, নেটওয়ার্ক সমস্যা ও রেট লিমিটের (`429` ও `5xx` স্ট্যাটাস কোড) মতো ক্ষণস্থায়ী সমস্যা ম্যানেজ করার জন্য ডিফল্ট হিসেবে এক্সপোনেনশিয়াল ব্যাকঅফ সহ অটোমেটিক রিট্রাই লজিক অন্তর্ভুক্ত থাকে। যেমন, Python SDK অটোমেটিক ট্রানজিয়েন্ট সমস্যা চারবার পর্যন্ত আবার চেষ্টা করে, যার মধ্যে প্রথমবার চেষ্টা করার আগে প্রায় ১ সেকেন্ড এবং সর্বাধিক ৬০ সেকেন্ড দেরি করে।

আপনি সরাসরি REST API অনুরোধ করলে বা আপনার আবার চেষ্টা করার লজিক কাস্টমাইজ করলে, অনুরোধ সফল হওয়ার সম্ভাবনা বাড়াতে এবং পরিষেবা ওভারলোড হওয়া আটকাতে এইসব পেশাদার পদ্ধতি অনুসরণ করুন:

- **এক্সপোনেনশিয়াল ব্যাকঅফ ব্যবহার করুন:** প্রথমবার আবার চেষ্টা করার আগে অল্প সময় অপেক্ষা করুন (যেমন, ১ সেকেন্ড), তারপর এক্সপোনেনশিয়ালি দেরি করার সময় বাড়ান (যেমন, ২ সেকেন্ড, ৪ সেকেন্ড, ৮ সেকেন্ড)।
- **জিটার যোগ করুন:** সব ক্লায়েন্ট যাতে একই সময়ে আবার চেষ্টা না করে, তার জন্য বিলম্বের সাথে র‍্যান্ডম "জিটার" যোগ করুন।
- **নির্দিষ্ট সমস্যার ক্ষেত্রে আবার চেষ্টা করুন:** শুধুমাত্র ক্ষণস্থায়ী সমস্যার (যেমন `429`, `408` বা `5xx`) ক্ষেত্রে আবার চেষ্টা করুন। ক্লায়েন্ট সমস্যার (যেমন `400`, `402` বা `403`) ক্ষেত্রে আবার চেষ্টা করবেন না কারণ সেগুলি ভুল API কী, প্রিপে ক্রেডিট শেষ হয়ে যাওয়া বা ভুল সিনট্যাক্সের মতো সমস্যা নির্দেশ করে।
- **সর্বাধিক কতবার আবার চেষ্টা করা হবে তা সেট করুন:** অসীম লুপ প্রতিরোধ করতে সর্বাধিক কতবার আবার চেষ্টা করা হবে তা নির্ধারণ করুন।

## মডেল প্যারামিটার সংক্রান্ত সমস্যার জন্য আপনার API কল চেক করুন

আপনার মডেল প্যারামিটার নিম্নলিখিত ভ্যালুর মধ্যে আছে কিনা তা যাচাই করুন:

|  |  |
| --- | --- |
| **মডেল প্যারামিটার** | **মান (রেঞ্জ)** |
| প্রার্থীর সংখ্যা | ১-৮ (পূর্ণসংখ্যা, Gemini ৩ ও ৪-এ কাজ করে না) |
| তাপমাত্রা | ০.০-১.০ (Gemini ৩.৬+ এবং ৪-এ উপেক্ষা করা হয়েছে; আগের Gemini ৩ মডেলে ডিফল্ট হিসেবে রাখুন) |
| সর্বাধিক আউটপুট টোকেন | আপনি যে মডেল ব্যবহার করছেন তার জন্য সর্বাধিক টোকেনের সংখ্যা নির্ধারণ করতে [মডেল পৃষ্ঠা](https://ai.google.dev/gemini-api/docs/models?hl=bn) ব্যবহার করুন। |
| TopP | ০.০-১.০ (Gemini ৩.৬+ এবং ৪-এ উপেক্ষা করা হয়েছে; আগের Gemini ৩ মডেলে ডিফল্ট হিসেবে রাখুন) |

প্যারামিটারের মান চেক করার পাশাপাশি, আপনি সঠিক
[API ভার্সন](https://ai.google.dev/gemini-api/docs/api-versions?hl=bn) (যেমন, `/v1` বা `/v1beta`) এবং
আপনার প্রয়োজনীয় ফিচার কাজ করে এমন মডেল ব্যবহার করছেন কিনা তা নিশ্চিত করুন। যেমন, কোনও ফিচার বিটা ভার্সনে রিলিজ হলে, সেটি শুধু `/v1beta` API ভার্সনে উপলভ্য হবে।

## আপনার কাছে সঠিক মডেল আছে কিনা তা চেক করুন

আমাদের [মডেল
পৃষ্ঠায়](https://ai.google.dev/gemini-api/docs/models?hl=bn) তালিকাভুক্ত কাজ করে এমন মডেল ব্যবহার করছেন কিনা তা যাচাই করুন।

## Thinking মডেলের সাথে বেশি লেটেন্সি বা টোকেন ব্যবহার

Gemini 3.x মডেলে ডিফল্ট হিসেবে থিঙ্কিং চালু থাকার কারণে প্রায়ই বেশি লেটেন্সি বা টোকেন ব্যবহার হয়। Gemini 2.5-এর পুরনো মডেলও ডিফল্ট থিঙ্কিং
ব্যবহার করে।

গুণমান উন্নত করার জন্য থিঙ্কিং মডেল ইন্টার্নাল রিজনিং টোকেন জেনারেট করে। এই
যুক্তি দেওয়ার প্রসেস, রেসপন্স লেটেন্সি ও মোট টোকেন খরচ, দুটিই বাড়িয়ে দেয়।

আপনি যদি কম লেটেন্সিকে অগ্রাধিকার দেন বা খরচ কমাতে চান, তাহলে থিঙ্কিং লেভেল কমাতে বা থিঙ্কিং বন্ধ করতে পারেন।

কনফিগারেশনের বিবরণ ও কোড স্যাম্পেলের জন্য,
[থিংকিং গাইড](https://ai.google.dev/gemini-api/docs/thinking?hl=bn#thinking-levels) দেখুন।

## নিরাপত্তা সংক্রান্ত সমস্যা

আপনার API কলে কোনও নিরাপত্তা সেটিংসের কারণে কোনও প্রম্পট ব্লক করা হয়েছে বলে দেখতে পেলে,
API কলে আপনার সেট করা ফিল্টার অনুযায়ী প্রম্পটটি পর্যালোচনা করুন।

আপনি `BlockedReason.OTHER` দেখতে পেলে, কোয়েরি বা উত্তর [পরিষেবার
শর্তাবলী](https://ai.google.dev/terms?hl=bn) লঙ্ঘন করতে পারে বা অন্য কোনও কারণে কাজ নাও করতে পারে।

## আবৃত্তি সংক্রান্ত সমস্যা

আপনি যদি দেখেন যে RECITATION-এর কারণে মডেল আউটপুট জেনারেট করা বন্ধ করে দিয়েছে, তাহলে
এর অর্থ হল মডেল আউটপুট নির্দিষ্ট ডেটার মতো হতে পারে। এটি সমাধান করতে, প্রম্পট / প্রসঙ্গ যতটা সম্ভব অনন্য করার চেষ্টা করুন। স্যাম্পলিং প্যারামিটার কাজ করে এমন পুরনো মডেলের জন্য, আপনি আরও বেশি টেম্পারেচার ব্যবহার করতে পারেন।

## বারবার টোকেন সংক্রান্ত সমস্যা

আপনি যদি বারবার আউটপুট টোকেন দেখতে পান, তাহলে সেগুলি কমাতে বা বাদ দিতে
নিম্নলিখিত সাজেশনগুলি ব্যবহার করে দেখুন। তাপমাত্রা অ্যাডজাস্টমেন্ট শুধুমাত্র আগের মডেলগুলিতে প্রযোজ্য
যা স্যাম্পলিং প্যারামিটার সমর্থন করে; Gemini 3 এবং Gemini 4 মডেলের জন্য, পরিবর্তে
প্রম্পট এবং সিস্টেম নির্দেশাবলী ওয়ার্কঅ্যারাউন্ড ব্যবহার করুন।

## প্রোজেক্ট সীমাবদ্ধ বা উপলভ্য নেই

আপনার API অনুরোধের উত্তরে `403 PERMISSION_DENIED` ("আপনার প্রোজেক্টের
অ্যাক্সেস প্রত্যাখ্যান করা হয়েছে") দেখানো হলে অথবা আপনার প্রোজেক্টের স্ট্যাটাস [Google AI Studio](https://aistudio.google.com/?hl=bn)-তে **সীমাবদ্ধ**, **ফ্রি টিয়ার
অনুপলভ্য**, **পেমেন্ট করতে হবে** অথবা **অনুপলভ্য** দেখানো হলে,
আপনার প্রোজেক্টের ক্ষেত্রে নিম্নলিখিত কোন বিভাগ প্রযোজ্য তা
চেক করুন:

### Gemini API ফ্রি টিয়ার উপলভ্য না থাকা

সব Google Cloud প্রোজেক্ট বা অ্যাকাউন্ট Gemini API-এর ফ্রি টিয়ারের জন্য উপযুক্ত নয়। আপনার প্রোজেক্টে ফ্রি টিয়ার ব্যবহার করার উপর বিধিনিষেধ থাকলে:

- **একই প্রোজেক্টে নতুন API key তৈরি করলে সমস্যার সমাধান হবে না।**
  Google Cloud প্রোজেক্ট লেভেলে Google উপযুক্ততা মূল্যায়ন করে।
- **এই প্রোজেক্টের সাথে Gemini API ব্যবহার করতে, আপনাকে অবশ্যই একটি অ্যাক্টিভ
  [Cloud Billing অ্যাকাউন্ট](https://aistudio.google.com/billing?hl=bn) লিঙ্ক করে পেড
  টিয়ারে** আপগ্রেড করতে হবে।
- মনে রাখবেন: কোনও প্রোজেক্ট পেড টিয়ারে আপগ্রেড করলে ফ্রি-টিয়ার কোটা আনলক হয় না।
  Google, [Gemini API-এর দাম](https://ai.google.dev/gemini-api/docs/pricing?hl=bn) অনুযায়ী পেড-টিয়ার ব্যবহারের জন্য বিল করে অথবা উপযুক্ত Google Cloud ক্রেডিট থেকে তা কেটে নেয়।

### Cloud Billing অ্যাকাউন্টে পেমেন্ট করতে হবে

আপনার প্রোজেক্ট আগে থেকেই কোনও Cloud Billing অ্যাকাউন্টের সাথে লিঙ্ক করা থাকলে এবং
**পেমেন্ট করতে হবে** (অথবা বকেয়া ব্যালেন্সের কথা উল্লেখ করে `403 PERMISSION_DENIED`
দেখালে):

- বকেয়া ব্যালেন্স সংক্রান্ত সমস্যার সমাধান করতে বা পেমেন্ট পদ্ধতি আপডেট করতে
  [AI Studio বিলিং পৃষ্ঠা](https://aistudio.google.com/billing?hl=bn) বা
  [Google Cloud বিলিং কনসোল](https://console.cloud.google.com/billing?hl=bn)
  দেখুন।
- আপনার বিলিং অ্যাকাউন্ট আবার ভাল অবস্থায় ফিরে এলে, আপনার প্রোজেক্ট অটোমেটিক
  API অ্যাক্সেস ফিরে পায়।

### লিক বা ব্লক করা API key

`403 PERMISSION_DENIED` সমস্যা সংক্রান্ত স্ট্যাটাসে যদি উল্লেখ করা থাকে যে আপনার API key ফাঁস হয়ে গেছে বা ব্লক করা হয়েছে:

- নতুন API কী তৈরি করতে এবং আপনার অ্যাপ্লিকেশনের ক্রেডেনশিয়াল আপডেট করতে, [AI Studio API কী পৃষ্ঠায়](https://aistudio.google.com/apikeys?hl=bn) যান।
- ক্লায়েন্ট-সাইড কোড বা পাবলিক রিপোজিটরিতে সরাসরি API key কখনও এম্বেড করবেন না।

### প্রোজেক্ট বা বিলিং অ্যাকাউন্ট নীতি সাসপেনশন

নীতি লঙ্ঘনের জন্য Google আপনার Google Cloud প্রোজেক্ট বা Cloud Billing অ্যাকাউন্ট সাসপেন্ড করলে, সংশ্লিষ্ট ইমেল আইডি চেক করুন। কোনও সাসপেনশন বিজ্ঞপ্তি পর্যালোচনা করতে
[Google Cloud Console](https://console.cloud.google.com/?hl=bn)-এ যান এবং
[প্রোজেক্ট সাসপেনশন নির্দেশিকা](https://cloud.google.com/resource-manager/docs/project-suspension-guidelines?hl=bn) অনুসরণ করুন।

## ব্লক করা বা কাজ করছে না এমন API key

আপনার Gemini API key ব্লক করা আছে কিনা তা কীভাবে চেক করবেন এবং
এই বিষয়ে কী করতে হবে তা এই বিভাগে বর্ণনা করা হয়েছে।

### 'কী' কেন ব্লক করা হয়েছে তা বোঝা

আমরা একটি দুর্বলতা শনাক্ত করেছি যেখানে কিছু API কী সর্বজনীনভাবে
প্রকাশিত হতে পারে। আপনার ডেটা সুরক্ষিত রাখতে এবং অননুমোদিত অ্যাক্সেস আটকাতে, আমরা
Gemini API অ্যাক্সেস করা থেকে এই পরিচিত ফাঁস হওয়া কীগুলি প্রোঅ্যাক্টিভভাবে ব্লক করেছি।

### আপনার 'কী' প্রভাবিত হয়েছে কিনা তা কনফার্ম করুন

আপনার 'কী' ফাঁস হয়ে গেছে বলে জানা গেলে, আপনি আর সেই 'কী' Gemini API-এর সাথে ব্যবহার করতে পারবেন না। আপনার কোনও API কী Gemini API কল করার জন্য ব্লক করা হয়েছে কিনা তা দেখতে এবং নতুন কী জেনারেট করতে আপনি [Google AI Studio](https://ai.google.dev/gemini-api/docs/api-key?hl=bn) ব্যবহার করতে পারেন। এছাড়াও, এইসব 'কী' ব্যবহার করার চেষ্টা করার সময় আপনি নিম্নলিখিত সমস্যা সংক্রান্ত মেসেজ দেখতে
পেতে পারেন:

```
Your API key was reported as leaked. Please use another API key.
```

### ব্লক করা API কী-এর জন্য অ্যাকশন

[Google AI Studio](https://ai.google.dev/gemini-api/docs/api-key?hl=bn) ব্যবহার করে আপনার Gemini API ইন্টিগ্রেশনের জন্য নতুন API কী জেনারেট করা উচিত। আপনার নতুন API কী যাতে সুরক্ষিত থাকে এবং সর্বজনীনভাবে প্রকাশ না হয়ে যায়, তা নিশ্চিত করতে আমরা আপনার API কী ম্যানেজমেন্ট পদ্ধতি পর্যালোচনা করার জন্য বিশেষভাবে সাজেস্ট করি।

### দুর্বলতার কারণে অপ্রত্যাশিত চার্জ

[বিলিং সংক্রান্ত সহায়তা কেস জমা দিন](https://console.cloud.google.com/support/chat?hl=bn)।
আমাদের বিলিং টিম এই বিষয়ে কাজ করছে এবং যত তাড়াতাড়ি সম্ভব আমরা আপডেট জানাব।

### লিক হওয়া 'কী'-এর জন্য Google-এর নিরাপত্তা সংক্রান্ত ব্যবস্থা

**আমার API কী ফাঁস হয়ে গেলে, Google কীভাবে আমার অ্যাকাউন্টকে অতিরিক্ত খরচ ও অপব্যবহার থেকে সুরক্ষিত রাখতে সাহায্য করবে?**

- আপনি [Google AI Studio](https://ai.google.dev/gemini-api/docs/api-key?hl=bn) ব্যবহার করে নতুন 'কী'র অনুরোধ করলে, আমরা API 'কী' ইস্যু করার দিকে এগোচ্ছি, যা ডিফল্ট হিসেবে শুধুমাত্র Google AI Studio-তে সীমাবদ্ধ থাকবে এবং অন্যান্য পরিষেবা থেকে 'কী' গ্রহণ করবে না।
  এটি অনিচ্ছাকৃতভাবে ক্রস-কী ব্যবহার করা আটকাবে।
- আমরা ডিফল্ট হিসেবে সেইসব API কী ব্লক করছি যেগুলি ফাঁস হয়ে গেছে এবং Gemini API-এর সাথে ব্যবহার করা হচ্ছে।
  এর ফলে খরচ ও আপনার অ্যাপ্লিকেশন ডেটার অপব্যবহার প্রতিরোধ করা সম্ভব হয়।
- আপনি [Google AI Studio](https://ai.google.dev/gemini-api/docs/api-key?hl=bn)-তে আপনার API কী-এর স্ট্যাটাস দেখতে পাবেন এবং আপনার API কী ফাঁস হয়ে গেছে বলে আমরা শনাক্ত করলে, অবিলম্বে ব্যবস্থা নেওয়ার জন্য আমরা আপনার সাথে যোগাযোগ করার চেষ্টা করব।

আপনাকে শুরু করতে সাহায্য করার জন্য কিছু মৌলিক ধারণা, কৌশল এবং পেশাদার পদ্ধতি
পরিচয় করিয়ে দেয়।

## টোকেন সীমা সম্পর্কে বোঝা

টোকেন ও তার সীমা কীভাবে গণনা করতে হয় তা আরও ভালভাবে বুঝতে আমাদের [টোকেন গাইড](https://ai.google.dev/gemini-api/docs/tokens?hl=bn) পড়ুন।

## পরিচিত সমস্যা

- API শুধুমাত্র কয়েকটি বেছে নেওয়া ভাষা সমর্থন করে। সাপোর্ট করে না এমন ভাষায়
  প্রম্পট জমা দিলে অপ্রত্যাশিত বা এমনকি ব্লক করা উত্তরও তৈরি হতে পারে। আপডেটের জন্য
  [মডেলের বিবরণ পৃষ্ঠা](https://ai.google.dev/gemini-api/docs/models?hl=bn)
  দেখুন।
