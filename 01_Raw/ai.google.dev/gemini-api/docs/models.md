## Muster für Modellversionsnamen

Gemini-Modelle sind in den Versionen *stabil*, *Vorabversion*, *aktuell* oder *experimentell* verfügbar.

### Stabil

Verweist auf ein bestimmtes stabiles Modell. Stabile Modelle ändern sich in der Regel nicht. Die meisten Produktionsanwendungen sollten ein bestimmtes stabiles Modell verwenden.

Beispiel: `gemini-3.6-flash`.

### Vorschau

Verweist auf ein Vorschaumodell, das für die Produktion verwendet werden kann. Für Vorschaumodelle ist in der Regel die Abrechnung aktiviert. Sie können strengere Ratenbegrenzungen haben und werden mit einer Frist von mindestens zwei Wochen eingestellt.

Beispiel: `gemini-2.5-flash-preview-09-2025`.

### Neueste

Verweist auf den neuesten Release für eine bestimmte Modellvariante. Dies kann ein stabiler, ein Vorschau- oder ein experimenteller Release sein. Dieser Alias wird bei jeder neuen Version einer bestimmten Modellvariante im laufenden Betrieb ausgetauscht. Bei funktionsgefährdenden Änderungen werden Sie **zwei Wochen im Voraus** per E-Mail benachrichtigt, bevor die Version hinter der neuesten Version geändert wird.

Beispiel: `gemini-flash-latest`.

### Experimentell

Verweist auf ein experimentelles Modell, das in der Regel nicht für die Produktion geeignet ist und strengere Ratenbegrenzungen hat. Wir veröffentlichen experimentelle Modelle, um Feedback zu erhalten und Entwicklern schnell unsere neuesten Updates zur Verfügung zu stellen.

Experimentelle Modelle sind nicht stabil und die Verfügbarkeit von Modellendpunkten kann sich ändern.
