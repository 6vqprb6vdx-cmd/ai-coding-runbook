# Antigravity-Vorschau

Ein leistungsstarker, verwalteter Agent für allgemeine Zwecke, der für autonome, mehrstufige Workflows entwickelt wurde. Dieses Modell plant, zieht Schlussfolgerungen, führt Code aus, verwaltet Dateien und durchsucht das Web in einer sicheren, isolierten Linux-Sandbox, die von Google gehostet wird.

Mit der Version vom September 2026 (`antigravity-preview-09-2026`) wird die Laufzeitumgebung mit verbessertem Prompt-Caching, nativen Tools für die Codesuche und effizienter Bearbeitung von Dateien im Zeilenbereich aktualisiert.
